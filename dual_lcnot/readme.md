# Dual LCNOT target-Z comparison

[shared_ancilla_distance3](shared_ancilla_distance3/readme.md) contains the exact dual LCNOT circuit used for the target-Z figure. [independent_3-3-3_pair](independent_3-3-3_pair/readme.md) contains the separately sampled standard reference and derived independent-pair curve.

Each configuration contains `target_z.stim`, `target_z_results.csv`, and the associated visualizations and simulation inputs.

Both datasets use 45 million shots per point. See [noise and decoding](../docs/SCIENTIFIC_LIMITATIONS.md) for the simulation settings.
